# Internal documentation

> Maintainer-only material. **Not user-facing.** Nothing in this directory is part of the published
> documentation set, and none of it carries support or stability guarantees.

This area holds design and review artifacts kept for their rationale and history:

- `plans/` — deep-dive design and review plans for the framework subsystems (qb-core, qb-io, the coroutine
  layer). These document findings, decisions, and technical-debt tracking at specific points in time. They
  are working notes, may be written in mixed languages, and are intentionally excluded from the user
  documentation tree under `../readme/`.

User documentation lives in `../README.md` and `../readme/`. Contribution guidance is in
`../CONTRIBUTING.md`.
